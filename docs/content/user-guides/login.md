# Logging in

The login page supports two entry methods:

- **VU ID and password** for regular accounts
- **VU SSO** for single sign-on accounts

## Password login

1. Open the Virtual Lab login page.
2. Enter your **VU ID**.
3. Enter your password.
4. Select **Login**.

If the credentials are invalid, the page shows an error and keeps you on the login screen.

## VU SSO login

If your account uses VU SSO, choose **Login through VU SSO** instead of entering a password.

If SSO authentication fails, the login page returns an error message and lets you try again.

## After login

Once authenticated, you are taken to the dashboard. From there you can open **My Instances** or **Settings** from the sidebar.
