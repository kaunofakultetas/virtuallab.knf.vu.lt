# Dashboard

The dashboard is the first page you see after logging in.

## What you see

- A list of your active instances
- Each instance name, status, and time remaining
- A warning when an instance is close to expiring

## Instance actions from the dashboard

- **Connect** opens the session for a running instance
- **Start** appears for stopped instances
- **Stop** appears for running instances
- **Extend runtime** renews the instance lease

## When an instance is expiring

If one or more instances are close to their `run_until` time, the dashboard shows a warning so you can renew them before they are removed.
